Countdown 倒数日

使用 Qt + kirigami 开发的跨平台倒数日应用，用来记录生日、纪念日、截止日期这些重要的日子，一眼就能看清还剩多少天。界面简洁现代，支持无重复、月重复、年重复三种倒数模式，可在指定日期发通知提醒，数据以 JSON 保存在本地，不上传任何服务器。 支持 Linux 与 Windows，Android 为实验性支持，提供中英文界面。

关于上传数据

纯本地存储，数据只属于你。

我们为你提供最安全的隐私保护。默认情况下，你的所有倒数日数据都以 JSON 格式保存在设备本地，我们没有任何中央服务器，也永远不会收集或上传你的任何私人数据。

如果你需要在多设备间同步，我们提供了完全由你掌控的 WebDAV 同步选项（高级功能，默认关闭）。数据只会传输并保存在你自己配置的网盘（如自建的 NAS、Nextcloud、坚果云等）中，开发者依然无法触及你的任何数据
